# Account Profile & security (wireframe reference)

Design source: `dockyrd-user-settings.html` export (board **Settings · Profile & security**).

Implemented route: `/settings/account/profile` (`AccountProfileSettingsPage`).

Sections on one page:

1. Profile (name, email)
2. Password
3. Two-factor authentication
4. Date & time
5. Active sessions

Legacy routes redirect here: `/settings/account/password`, `/settings/account/security`, `/settings/account/regional`.
