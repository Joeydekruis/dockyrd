Operations

CLI reference

The dockyrd binary is both the server and its admin tool. Run commands as root on the server.

Commands

CommandWhat it does
dockyard serveStarts the server. systemd runs this for you.
dockyard initFirst-time setup: keys, database, network, proxy. Safe to rerun.
dockyard setup-tokenPrints a new one-time setup link, as long as no owner exists.
dockyard admin reset-password <email>Resets a user's password from the server.
dockyard admin disable-2fa <email>Turns off two-factor for a locked-out user.
dockyard update [--version]Installs the latest or a specific release.
dockyard doctorChecks Docker, ports, DNS, disk, proxy config and clock, and suggests fixes.
dockyard proxy dumpPrints the Caddy configuration currently loaded.
dockyard backupWrites a snapshot of the control-plane database.
dockyard versionPrints version, commit and build date.

Files and paths

PathContents
/usr/local/bin/dockyardThe binary
/etc/dockyard/Master key and optional dockyrd.env
/var/lib/dockyard/dockyrd.dbControl-plane database (SQLite)
/var/lib/dockyard/backups/Daily snapshots, seven kept
/var/lib/dockyard/sites/Static site releases

Logs go to journald: journalctl -u dockyrd -f.
