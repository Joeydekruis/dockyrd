# Security

If you discover a security issue, please report it responsibly.

## Reporting

Email **joey@derisory.nl** with:

- Description and impact
- Steps to reproduce
- Affected version or commit

Do not open public GitHub issues for exploitable vulnerabilities.

## Scope

Dockyard: the `dockyard` binary, embedded dashboard, installer, and documented API surfaces.

User-deployed workloads (your apps, databases, Garage) remain your responsibility; report only issues in Dockyard’s control plane or default templates.

## Response

We aim to acknowledge reports within a few business days and coordinate disclosure after a fix is available.

See also [`docs/BRIEFING.md`](docs/BRIEFING.md) auth and secrets handling.
